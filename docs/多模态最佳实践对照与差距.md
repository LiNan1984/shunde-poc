# 多模态智能体最佳实践对照与差距报告

> 参照：`ai-agent-book/chapter4`（实验 4-2 perception-tools「多模态感知」+ 4-3 multimodal-agent 三范式，辅以 4-1 主动发现 / 4-4 执行工具）。
> 对照对象：`poc/kb_mcp` 多模态文件问答助手（用例 2-1/2-2）。
> 结论日期：2026-09-14。缺口处置状态以本日实现为准。

## 一、结论

两边定位不同：chapter4 是**答案生成侧**范式（原生多模态 / 先抽文本 / 工具化追问），POC 是**入库+检索侧**管线。POC 原先只覆盖「先抽文本」一种范式且停在检索层。参照项目里最值得抄的实践（答案侧原生视觉作答、按需深挖工具、真重排序、可量化评测）当时全部缺失，现已补齐（见第三节）。

POC 原有、且**强于参照**的部分（保持不动）：BM25+向量 RRF 混合检索、查询四分类（overview/multimodal/short/fact）、邻居扩展、页级去重、表格三格式（csv/html/json）、MinerU 集成、POC_WORKSPACE 沙箱、embed 失败不静默降级、「表格定位文件 + pandas 精算」路由。
