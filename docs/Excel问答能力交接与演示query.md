# Excel 问答能力交接：该问什么、效果会不会更好

| 项 | 内容 |
|----|------|
| 场景 | 顺德 POC 场景① Excel/CSV 问答 |
| 代码 | `poc/excel_guard_mcp/`（MCP `excel-guard`）+ `poc/skills/excel-qa-bank/SKILL.md` |
| 演示工作簿 | `poc/fixtures/收支明细_顺德.xlsx`（Sheet1，266 条明细 × 14 列；由仓库根目录同名流水表复制，地名「青岛」已换成「顺德」） |
| 日期 | 2026-09-15 |

---

## 1. 先回答两个问题

### 1.1 上传任意 Excel，回答效果有什么不同？会更好吗？

**同一条链路，不会因为「这是不是某份固定卷」而换引擎。** 文件只要落在 `POC_WORKSPACE`（演示时一般是仓库根）里，流程都是：

```
护栏（损坏 / 编码 / 超大分块）
    → describe_workbook 看清 sheet、行列、表头、前几行
    → 可选 sheet_to_markdown 只看一小段
    → pandas / openpyxl 对原文件计算或写回
```

| 以前（只有三护栏） | 现在 |
|--------------------|------|
| Agent 容易按旧剧本去找「交易类型 / 网点名称」这类**不存在的列** | 先 `describe_workbook`，按**这张表真实的列名**写 pandas |
| 「先看几行」只能盲 `head()`，大表还容易整表进上下文 | 小区间用 `sheet_to_markdown`；合计仍用代码算 |
| 多文件「哪份表里有收款行」只能逐个打开 | `ingest_spreadsheet` 只索引文件名/sheet/表头/样例，检索**定位文件**，再 pandas |

**数字会不会更准：** 筛选、合计、写回的答案仍然是 pandas 算出来的，不是模型看着表格「猜」的。  
列名写对了，数字和以前一样准；**变好的是「任意一张表」上少认错列、少编造列。**  
把整表转成 markdown 塞进模型、或把每一行灌进知识库，**不会**让合计更准，大表还会爆上下文、切片还会拆掉表结构。

**不会自动更好的情况：**

- 问题用的词在表里对不上（问「转账汇出」，表里只有「交易附言=转账支出」）——要按真实列值问，或允许 agent 先列枚举值再筛。
- 文件不在工作区 → `path_denied`。
- 损坏 / 旧 `.xls` → 护栏直接停，这是预期。
- 把合计题交给知识库 `answer_knowledge` → 检索切片不会做加减。

### 1.2 我应该问什么 query？

不要把 [excel-12题标准答卷.md](excel-12题标准答卷.md) 的 Q4「容桂支行 3 月转账汇出」原样打在这份收支明细上——那份题面假定列是 `网点名称 / 交易类型 / 借方金额`，**这份表没有这些列**。

本工作簿真实列名：

`交易日期` `PTA_BRANCH` `PTA_CIFNO` `PTA_ACCNO` `付款姓名` `PTA_ACCBRANCH` `金额` `PTA_EFTNO` `交易对手` `收款行` `币种` `交易附言` `交易渠道` `商家名称`

日期大约 `20240118`～`20261212`（8 位数字，不是带横杠的日期）。收款行是「顺德银行李沧支行」这类。渠道有微信支付 / 支付宝 / 手机银行等。

下面 query 可直接复制到 **Excel问答助手**（`excel-qa-bank` + `excel-guard`）。先上传或指定 `poc/fixtures/收支明细_顺德.xlsx`。

## 2. 推荐现场 query（按演示顺序）

### A. 先证明「看见了真实结构」（新能力，必问）

> 这个 Excel 有几张表？每张多少行多少列？表头是什么？先不要算合计。

**期望：** 1 张表 `Sheet1`，**267 行（含表头）× 14 列**；表头与上一节 14 个字段一致。  
**看点：** 日志里应有 `describe_workbook`，不要一上来 `pd.read_excel` 猜列。

> 先给我看表头和前 3 行长什么样。

**期望：** markdown 或表格预览，出现 `交易日期`、`收款行`、样例里有「顺德银行…」。不要把 266 行全贴进回复。

### B. 筛选 / 查询（pandas 精算）

> 收款行是「顺德银行李沧支行」的有多少笔？金额合计多少？

> 2026 年 6 月、交易渠道是微信支付的流水，列出日期、金额、交易对手、商家名称。

> 交易附言是「餐饮消费」的前 10 笔。

> 商家名称或交易对手里带「地铁」的有几笔？

口径：金额列有正有负（支出多为负），合计请原样加总并说明正负含义，不要偷偷取绝对值，除非用户要求。

可核对（本工作簿当前内容，复算以文件为准）：

| 条件 | 笔数 | 金额合计（约） |
|------|------|----------------|
| 2026 年 6 月 × 微信支付 | 6 | -11656.51 |
| 交易对手或商家含「地铁」 | 12 | — |

### C. 聚合 / 分析

> 按交易渠道汇总：每个渠道多少笔、金额合计，按笔数从高到低。

> 按交易附言汇总笔数，只看前 8 类。

> 金额最低（支出最大）的 5 笔是哪几笔？给出日期、金额、收款行、附言。

当前渠道大致分布（复算以文件为准）：支付宝 128、微信支付 71、手机银行 24、POS机 21、柜台 12、ATM 9。

### D. 写回（用例要求的「写入」）

> 把收款行是「顺德银行李沧支行」的明细另存成新 Excel，不要改原文件，告诉我新路径。

> 加一列「是否微信」，交易渠道等于微信支付标「是」否则「否」，另存一份。

**期望：** 路径在工作区内；原文件未覆盖；写完后 skill 会走 `audit_workbook`（库内函数，不是 MCP 工具）。

### E. 多轮（docx 明确要考上下文）

先问 B 里李沧支行那句，**同一会话**再追问，不要重贴文件、不要重述条件：

> 这里面金额最低的三笔是哪三笔？

> 这三笔合计多少？占刚才那批李沧支行全部金额的多少？

### F. 多文件定位（新能力，可选）

工作区再放一份列名完全不同的表（例如只有「胶州 / 网点」），然后问：

> 哪个文件的表头里有「收款行」或样例里有「顺德银行」？定位到文件后，再算李沧支行笔数。

**期望：** `ingest_spreadsheet` + `search_knowledge` 只用来找文件；**笔数必须再 pandas**，不能用检索片段当合计。

### G. 护栏三道（用例 1-2，用现成 fixture，不要用收支明细）

| 问法 | 文件 | 期望 |
|------|------|------|
| 帮我打开这份表 | `poc/fixtures/corrupt.xlsx` | `detect_corrupt_workbook` → 损坏，停止读写 |
| 读出这份名单 CSV | `poc/fixtures/encoding_gbk.csv` 或 `encoding_latin1.csv` | 先 `detect_encoding`，不要当 UTF-8 硬读 |
| 这个大表 amount 总和、平均是多少，要分块算 | `poc/fixtures/large_chunk_demo.xlsx` | `chunk_large_workbook` 两块；sum=189031500.0，mean=31505.25，count=6000 |

## 3. 不要这么问（容易显得「没变好」）

| 不推荐 | 原因 |
|--------|------|
| 「按网点名称 / 交易类型汇总」打在收支明细上 | 本表没有这两列；应问「收款行 / 交易附言 / 交易渠道」 |
| 「根据知识库告诉我六月合计」 | 表格合计不是 RAG 题 |
| 「把全表转成 markdown 再回答」 | 266×14 还能撑，但路径错误；更大的表会爆上下文 |
| 把 PDF 信贷政策题打给 Excel 助手 | 应切到多模态助手 `kb-qa-bank` |
| 工作区外的绝对路径 | 沙箱拒绝，与问答能力无关 |

---

## 4. 接手人装配要点（和 query 同等重要）

1. Console 智能体挂 `excel-qa-bank` Skill + `excel-guard` MCP。  
2. MCP 工具现在是 **5 个**：`detect_corrupt_workbook`、`detect_encoding`、`chunk_large_workbook`、`describe_workbook`、`sheet_to_markdown`。旧交接里写的「3 工具」已过时。  
3. 多文件定位再挂 `kb-qa` 的 `ingest_spreadsheet`（知识库那路还有 PDF 工具和 `analyze_page`，与 Excel 算数无关）。  
4. `env.POC_WORKSPACE` 必须覆盖演示文件所在目录；上传后的文件也要在这个根下。  
5. 评委真题若列名不同：**不要改代码**，用第 2 节 A 类问题先让助手报出真实表头，再按表头改口问。

更完整的 12 类题型模板（读取 / 查询 / 分析 / 写入）仍见 [excel-12题标准答卷.md](excel-12题标准答卷.md)；装配步骤见 [excel-agent装配剧本.md](excel-agent装配剧本.md)。本文只解决「这份顺德收支明细 + 任意新表，现场该打哪几句」。
