## 5. 基础设施与运维

- **VPS**（root@72.60.193.189，4C/15G/2G swap）：ES 8.17 `127.0.0.1:19200` + MySQL 8 `127.0.0.1:13306`（独立端口，不占用宿主 9200/3306）。swap 100% 占满是常态非告警；available < 2GB 危险。**内存监控 skill 已就位**：`.claude/skills/vps-mem-watch/`（一次性体检 + 60s 持续监控；盯防 `kb_ingest_one.py` 的 RSS 失控复发）。
- **CI**：`.github/workflows/tests.yml` — pytest 全量 + Excel 黄金评测 self-test（必须 100%）+ KB 黄金评测（hit-rate ≥ 0.8）。无密钥设计（测试离线确定性后端）。注意三处环境对齐：`fonts-wqy-zenhei`（与部署镜像一致）、tesseract 缺省时 OCR 断言自动门控、submodule 无 tag 时版本探测容错。
- **Docker**：`poc/deploy/Dockerfile.poc`（python:3.13-slim + wqy 字体，<500MB）。
- **QwenPaw**：官方 submodule，随上游更新（测试钉 v2 主版本线，不钉具体 tag）。

## 7. 红线（违反即事故）

1. **密钥不进仓库**：API Key 只走 `QWENPAW_SECRET_DIR` / 环境变量 / gitignored `.env`；VPS 密码只存在于会话中。
2. **沙箱**：所有文件操作限 `POC_WORKSPACE` 内，越界拒绝且不回显路径。
3. **数值答案必须来自代码计算**：不得用知识库切片/整表 markdown 让模型"猜"合计；检索只负责定位文件。
4. **写回必审计**：`audit_workbook` 的 `must_fix` 未清零不得交付。
5. **不虚报**：GALASYBASE 无官方镜像时图库走本地 graph.json，答案里不得写成"已写入 Galaxybase"；MinerU/OCR 不可用时的降级要如实说明。
6. **改能力必跑评测**：改动 excel-qa / kb 任何能力后跑对应黄金评测，准确率变化是唯一验收语言；新增 MCP 工具必须同步 smoke 脚本工具数。
