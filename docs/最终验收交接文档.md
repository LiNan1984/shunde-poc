## 三、演示流程（评委当天用）

### 3.1 5 分钟基线（必跑）

```bash
cd <REPO_ROOT>
source .venv/bin/activate
uv pip install -r poc/requirements.txt     # 装依赖
git -C QwenPaw describe --tags --exact-match   # → v2.0.0
pytest poc/tests tests/ -q                 # → 240 passed, 1 skipped
python -m poc.excel_guard_mcp </dev/null    # → exit 0
python -m poc.report_mcp       </dev/null    # → exit 0
python -m poc.ops_mcp          </dev/null    # → exit 0
```

### 3.2 场景④ 一键 demo

```bash
python scripts/report_demo.py
# 产出: poc/fixtures/report_demo/out/report.docx
# 内容: 5 张 PNG 图 + 1 个交叉表 + 标题/段落的 docx（中文宋体）
```

### 3.3 三个 MCP stdio 彩排

```bash
python scripts/mcp_stdio_smoke.py
# 输出: 三个 server 全部 "ok": true；excel-guard 3 工具 + report-visualizer 7 工具 + ops-data 3 工具 = 13
```

### 3.4 场景③ HOOK 埋点验证

```bash
qwenpaw plugin install <REPO_ROOT>/poc/plugins/ops-telemetry
# 触发一次请求 →
tail -f $POC_WORKSPACE/telemetry/<UTC-date>/ops.jsonl
# 期望见到 5 类事件: call_volume / token_usage / tool_outcome / latency / identity
```

### 3.5 场景⑤ /health 验证

```bash
qwenpaw plugin install <REPO_ROOT>/poc/plugins/health
curl http://localhost:8080/api/poc/health
# 期望: {"status":"ok"}
```

### 3.6 场景⑤ 容器验证（需 docker 环境）

```bash
docker build -f poc/deploy/Dockerfile.poc -t shunde-poc:dev .
docker images shunde-poc:dev               # 期望 < 500MB
docker run --rm -p 8080:8080 shunde-poc:dev
curl http://localhost:8080/api/poc/health  # → {"status":"ok"}
```

### 3.7 安全攻击向量回归（覆盖场景① + 场景④）

```bash
pytest poc/tests/test_security_regressions.py -v
# 期望: 8 passed（最终组件、最终symlink、自循环symlink、越界、POC_WORKSPACE=/、不存在目录、tool继承、MemoryError审计）
```

### 3.8 Console 端手工步骤（仅人工）

按 `poc/README.md` 中三个 MCP（`mcp-excel-guard.json` / `mcp-report-visualizer.json` / `mcp-ops-data.json`）的样例，把每个 `<REPO_ROOT>` 替换为实际路径后导入；把 `poc/skills/` 加到 `skill_paths` 后从技能池下发 3 个 Skill；按演示剧本在 Console 智能体工作区里把 MCP+Skill 绑定到目标智能体。
