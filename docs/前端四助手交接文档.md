
启动备忘：

```bash
# 后端
cd /Users/linan/Desktop/aicode/shunde/QwenPaw
QWENPAW_AUTH_ENABLED=false .venv/bin/python -m qwenpaw app --host 127.0.0.1 --port 8088
```

## 2. 四个助手分别怎么问（前端能看到的效果）

### Excel问答助手

切到该 Agent，左侧 Files 可见三份表。

- `这个损坏表.xlsx 是不是坏了`
- `乱码表示例.csv 是什么编码，帮我读出来`
- `超大表示例.xlsx 要不要分块`

应先走 `detect_corrupt_workbook` / `detect_encoding` / `chunk_large_workbook`。

### 多模态文件助手

`知识库/` 已解压行方 zip 的 7 个 PDF。已入库（前几页，MinerU + doubao-embedding-vision）：

- 结构分化的宏观经济及再平衡思路 → 问 `再平衡思路是什么`
- 中国经济：2026，承前启后 → 问 `承前启后是什么意思`
- NIFD 公共养老基金 → 问 `公共养老基金怎么投资`
- 东吴证券 AI 经济学 → 问 `AI 两类金融风险` / `技术革命`
- 夹具 `信贷政策.pdf` → 问 `逾期90天认定标准`、`表格里的经营贷款利率`

未全量入库（太大/扫描）：统计年鉴 37MB、CMF 75MB、置身钉内 35MB。zip 本身 **未进 git**（147MB）。

### 运营助手

HOOK `poc-ops-telemetry` + 插件 `poc-health`（`GET /api/poc/health` → `{"status":"ok"}`）。

- `今天调用量怎么样`
- `最近一次失败的工具是什么`
- `token 用量`
- `哪个工具用得最多`

数据：`~/.qwenpaw/telemetry/YYYY-MM-DD/ops.jsonl`。没有文件时必须说「暂无埋点」，禁止编造。

### 报告可视化助手

- 把下面整段贴进 Chat（交差表 + 五类图 + docx）：

```
用工作区 分行业务.json 生成 docx 报告：交叉表（支行×产品汇总 amount），
柱状图、折线图、饼图、散点图、热力图各一张。标题「顺德农商行 2025Q3 零售业务报告」，
保存到 output/零售业务报告.docx
```

生成后在 Files 里看 docx。
